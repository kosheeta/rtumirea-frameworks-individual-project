# Сервис учёта использованных источников

## Назначение

Приложение для учёта источников, используемых в научных и учебных
исследованиях. Позволяет фиксировать источники и их авторов,
отслеживать актуальность источника и формировать библиографическую
запись для списка литературы.

## Целевая аудитория

Студенты, аспиранты и преподаватели, ведущие исследовательскую работу
и нуждающиеся в структурированном учёте источников для своих работ.

## Предметная область

Учёт использованных источников литературы: у каждого источника есть
автор, название, год публикации и ссылка; источники группируются в
рамках конкретного исследования, а для итоговой работы требуется
проверять источники на полноту данных и оценивать их актуальность.

## Основные сущности

- Исследование (научная или учебная работа, для которой собираются
  источники)
- Источник (статья, книга, публикация со ссылкой)
- Автор (автор источника)

## Возможности

- учёт исследований и относящихся к ним источников;
- добавление и удаление источников;
- поиск источников по автору или названию;
- фильтрация и сортировка источников по году публикации;
- проверка полноты данных источника;
- формирование библиографической записи источника;
- оценка актуальности источника по его возрасту;
- статистика по источникам исследования (количество, средний год
  публикации, число актуальных и устаревших источников).

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `sources.py` — функции работы с источниками;
- `researches.py` — функции работы с исследованиями и статистикой;
- `storage.py` — сохранение и загрузка данных в формате JSON;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы данных (`researches.json`, `sources.json`);
- `tests/` — автоматизированные тесты pytest.

## Требования

- Python 3.9+;
- pytest;
- flake8.

Установка зависимостей:

```
pip install -r requirements.txt
```
