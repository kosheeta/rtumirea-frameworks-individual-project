# Сервис учёта использованных источников

## Назначение
Приложение для учёта источников, используемых в научных и учебных
исследованиях. Позволяет фиксировать источники и их авторов,
отслеживать актуальность источника и формировать
библиографическую запись для списка литературы.

## Целевая аудитория
Студенты, аспиранты и преподаватели.

## Предметная область
Учёт использованных источников литературы: у каждого источника есть автор,
название, год публикации и ссылка; источники группируются в рамках
конкретного исследования, а для итоговой работы требуется проверять
источники на полноту данных и оценивать их актуальность.

## Основные сущности
- Исследование
- Источник
- Автор

## Основные функции
- проверка полноты данных источника (наличие автора, названия и года);
- формирование библиографической записи источника в текстовом виде;
- расчёт возраста источника в годах на текущую дату;
- определение актуальности источника по его возрасту.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
